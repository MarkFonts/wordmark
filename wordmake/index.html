WORDMAKE — spike

Two animators, one stateAt(t) each, through both emitters. Everything on the checkerboard is an animated SVG: no fonts, no scripts, no external references, transparent, glyphs as outlines. The same stateAt feeds resvg for the video. Copy is the Cal.com set; there is no interface yet, so this page is the spike's output, not the tool.
